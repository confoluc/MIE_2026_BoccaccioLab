# MIE_2026_BoccaccioLab

Scripts and notebooks for image processing and quantitative analysis of **membraneless organelles (MLOs) and biomolecular condensates in confocal microscopy images**.

This repository contains Fiji/ImageJ macros and Python notebooks developed for analysis of **membraneless organelles (MLOs) and biomolecular condensates in confocal microscopy images**. These scripts can be applied to workflows including segmentation, spatial overlap analysis, object randomization, autocorrelation analysis, and quantification of protein recruitment to MLOs.

# Macros and notebooks

## Fiji/ImageJ macros

| File                                 | Description                                                                                                                                                                                                                                               |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`ACF.ijm`**                        | Calculates autocorrelation profiles for a set of ROIs using the van Steensel translation randomization method. Extracts **Translation** and **Pearson correlation** values from each profile and saves them as individual CSV files.       |
| **`ROIs_To_Masks.ijm`**              | Converts each ROI in an ROI set into an individual binary mask. Each ROI is isolated from the corresponding image and saved as a TIFF mask.                                                                                                               |
| **`contacts_by_overlap.ijm`**        | Quantifies spatial overlap between two sets of binary images. The two corresponding images are multiplied and the resulting objects are analyzed with **Analyze Particles**, producing a summary of overlapping or contacting objects.                      |
| **`contacts_by_overlap_RANDOM.ijm`** | Performs the same overlap analysis as `contacts_by_overlap.ijm`, but compares each Channel 2 image against multiple randomized Channel 1 images contained in corresponding subfolders. Used to generate randomized controls for spatial-contact analysis. |
| **`cytoplasmic_ROIs.ijm`**           | Generates cytoplasmic ROIs from cell and nuclear ROI sets. Cell and nuclear ROIs are converted to masks, the nuclear mask is subtracted from the cell mask, and the resulting cytoplasmic region is eroded and converted into ROIs.                       |
| **`duplicate_by_ROIs.ijm`**          | Splits an image into individual images corresponding to a ROI in a set of ROIs. Each resulting image is saved as a separate TIFF.                                                |
| **`ilastik_MLOs_count.ijm`**         | Quantifies MLOs within individual cell ROIs using segmentation masks generated by ilastik. Objects are detected using **Analyze Particles** with a minimum size threshold and the resulting particle-summary tables are saved as CSV files.               |
| **`label_masks_from_binary.ijm`**    | Converts binary segmentation masks into labeled object masks using **Analyze Particles → Count Masks**. Each detected object receives a distinct pixel label, allowing individual MLOs to be identified and subsequently analyzed or randomized.          |

## Python notebooks

| File                                        | Description                                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`ACF_Notebook_MIE2026.ipynb`**            | Analyzes autocorrelation function (ACF) curves generated from microscopy data. Loads and filters ACF data, visualizes individual curves, fits curves using a **double-Gaussian model**, and calculates **full width at half maximum (FWHM)** values.                                                                                     |
| **`Cellpose_Notebook_MIE2026.ipynb`**       | Performs **cell and nuclear segmentation using Cellpose**. Allows model parameters to be tested on individual images before applying the selected parameters to a batch of images and exporting segmentation results.                                                                                                                    |
| **`Randomize_MLOs_Notebook_MIE2026.ipynb`** | Randomly redistributes labeled MLOs within a user-defined allowed area. Objects retain their original shape and label while being relocated without overlap. Multiple valid randomized images can be generated for each input image and saved as TIFF files.                                                                             |
| **`Recruitment_to_MLOs_MIE2026.ipynb`**     | Performs quantitative analysis of **protein recruitment to MLOs**. Combines fluorescence channels with MLO segmentation and cell ROIs, performs quality control, measures signal inside MLOs and in surrounding regions, calculates condensed/soluble signal ratios, and generates plots for comparison between experimental conditions. |

# Requirements

## ilastik

The segmentation protocol for MLOs requires [ilastik](https://www.ilastik.org/download) (release 1.4.2).

## Fiji / ImageJ

The Fiji macros require [Fiji](https://imagej.net/software/fiji/) (release 2.18.0).

Some macros use additional Fiji functionality or plugins, including functionality for Colocalization analysis.
Check the individual macro before use if working with a different Fiji installation or version.

## Python

The notebooks are designed to be uploaded to Google Colab, so no local Python installation is required. Installation of required packages is included in the notebooks, including Cellpose (release 4.2.1) for cell and nuclei segmentation.

Clone the repository:


For Fiji macros, open the `.ijm` file in Fiji.

For Python notebooks, upload the `.ipynb` to Google Drive and open with Colaboratory.

# Usage notes

Most macros operate on batches of files and rely on corresponding files being stored in matching order or with matching names.

**Always test a script on a small subset of the dataset before running it on the complete dataset.**

Several workflows also generate intermediate files that serve as inputs for subsequent analysis steps. For example, labeled MLO masks generated by `label_masks_from_binary.ijm` are to be subsequently used by the MLO randomization workflow.
